# TradeMindMZ V7.2

Final pre-GitHub stabilization pass on the V7 release.

## Critical fixes

- Added `open_demo_trade_v2(jsonb)` as a single-argument PostgREST wrapper. This avoids the named multi-argument RPC schema-cache resolution failure seen in the V6 APK while retaining the atomic server-side balance debit + trade insert.
- Kept `00043_refresh_demo_rpc_schema_cache.sql` and added a second explicit PostgREST reload in `00044_demo_trade_rpc_json_wrapper.sql`.
- Demo trade creation still uses the authenticated user's `auth.uid()` inside the server function; the client no longer supplies `p_user_id` to the public RPC wrapper.
- Preserved automatic demo-account initialization through `ensure_demo_account()`.
- Preserved Pionex USDT-M balance through the documented `/uapi/v1/account/balances` Futures endpoint.

## UI/data review

- Dashboard keeps V5/V7 Matrix terminal styling.
- Live Pionex balance, Pionex open positions and Demo open trades remain separated.
- 7D / 30D / 90D / ALL performance filters remain available.
- Live BUY reads the same normalized Futures balance source as the Dashboard.

## Safety

- No new live-trading endpoint is introduced by V7.2.
- Demo RPC remains security-definer and restricted to `authenticated`.
- No secrets or `.env.local` files are included in the release ZIP.
- Removed the Dashboard's misleading `500.00 USDT` fallback when the demo account is missing; the dashboard now shows `Loading…`, the actual persisted balance, or an explicit unavailable state.
