# TradeMindMZ V7.2

V7.2 keeps the complete V7.1 functional fixes and upgrades the Dashboard into a dedicated Matrix trading terminal UI.

## Included from V7.1
- Stable JSON single-argument demo RPC wrapper (`open_demo_trade_v2`) to avoid PostgREST named-argument schema-cache failures.
- Automatic demo-account initialization.
- Official Pionex USDT-M Futures balance source (`/uapi/v1/account/balances`).
- Live BUY/server preflight uses the normalized Futures balance.
- Dashboard no longer masks missing demo account data with a fake 500 USDT fallback.

## V7.2 UI
- Four terminal KPI tiles for Live Balance, Futures Equity, Demo Today P/L, and Live-period P/L.
- Large portfolio performance monitor with 7D/30D/90D/ALL filters.
- Dedicated Live Positions and Demo Open Trades panels.
- Performance Summary, AI Insight, Recent Positions, Recent Demo Trades, Market Overview, and Terminal Status.
- Mobile-specific bottom navigation.
- Stronger Matrix terminal depth: glass panels, grid, scanline, neon edge treatment, sparklines and compact status ribbons.
- LIVE and DEMO states are visually separated.
